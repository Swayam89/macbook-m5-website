Process

Third-generation 3-nanometer technology.

One die holds every processor on this page. Unified memory sits right beside it.

Unified memory

153GB/s of memory bandwidth.

Nearly 30 percent more than M4, shared by the CPU, GPU and Neural Engine. Configure up to 32GB.

Particle rate scaled to Apple's "nearly 30 percent." Illustrative.

CPU

Ten cores: 4 super, 6 efficiency.

Apple now calls its performance cores super cores. Switch the load to see which cluster picks up the work.

GPU

A Neural Accelerator in every GPU core.

Ten cores, ten accelerators. Over 4x the peak GPU compute of M4, plus a third-generation ray-tracing engine with up to a 45 percent graphics uplift in apps that use ray tracing.

Neural Engine

The 16-core Neural Engine is still here.

So on-device models have two places to run: the accelerators inside the GPU, and this.

Liquid Retina XDR

1600 nits, only where the picture asks for it.

The 14.2-inch display holds 1000 nits sustained full-screen and reaches 1600 nits peak for HDR content, with a 1,000,000:1 contrast ratio. ProMotion refreshes at up to 120Hz.
